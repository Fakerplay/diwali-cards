# Diwali Cards

An interactive 3D carousel of four Diwali cards, each with its own live effect:

| Card | Theme |
|---|---|
| Diya | Light · Hope |
| Rangoli | Colour · Welcome |
| Phuljhadi | Spark · Joy |
| Genda | Marigold · Blessing |

Inspired by elemental card interactions. Designed and directed by Shubham Shinde; built with AI.

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Files

- `index.html`: page and card markup
- `style.css`: layout and card styling
- `script.js`: carousel, effects and a bundled copy of three.js (r160, MIT)
- `fx/`: textures (flame, powder, marigold, rangoli)
- `icons/`: card icons
